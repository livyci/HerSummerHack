# Summit Outfitters — Smart Store

A frontend-only React + Vite + TypeScript web app for an outdoor gear store, built for the Scandit hackathon. It simulates Scandit barcode scanning through manual `product_code` entry, and uses Anthropic's Claude AI for natural-language product recommendations, side-by-side product comparisons, and store-owner promotion suggestions. Product data (249 SKUs across 69 products) is loaded from a local JSON file at runtime, so there is **no backend required** to run the app.

## Features

The app has three pages, served via React Router:

### Discover (`/`)
- Describe what you need in plain language (e.g. "lightweight tent for two people in the rain").
- Claude recommends matching products from the catalog.
- Discounted items are highlighted so deals stand out.
- Add any recommendation to your shopping list with one click.

### Shopping (`/shopping`)
- Manage your shopping list — add, review, and remove items.
- "Scan" a barcode by typing a product's `product_code`, simulating a Scandit scanner.
- Browse the full store inventory.
- Scanning a product that shares a category with something already on your list opens an **AI-powered compare modal** so you can decide between them.

### Admin (`/admin`)
- A store-owner analytics dashboard computed at runtime from the product data.
- Inventory value, stock-by-zone breakdown, and low-stock alerts.
- Discount-performance pie chart and category insights.
- AI-suggested promotions generated by Claude.

## Tech Stack

| Layer            | Choice                                                              |
| ---------------- | ------------------------------------------------------------------- |
| Framework        | React 19 + Vite + TypeScript                                        |
| Styling          | Tailwind CSS                                                        |
| State management | Zustand                                                             |
| Routing          | React Router v6                                                     |
| Charts           | Recharts (Admin dashboard)                                          |
| AI               | `@anthropic-ai/sdk` with model `claude-sonnet-4-6`, called directly from the browser via `dangerouslyAllowBrowser` |
| Data             | No backend — loaded from `dataset/products.json` at runtime          |

## Getting Started

The app lives in the `frontend/` folder.

1. **Enter the app directory**

   ```bash
   cd frontend
   ```

2. **Configure your Anthropic API key**

   ```bash
   cp .env.example .env
   ```

   Then edit `.env` and set `VITE_ANTHROPIC_API_KEY` to a real Anthropic API key (get one from the [Anthropic Console](https://console.anthropic.com/)).

   > Note: this key is used directly in the browser via `dangerouslyAllowBrowser`. That is fine for a hackathon/demo, but **not for production** — in a real deployment you would proxy Claude calls through a backend so the key is never exposed to the client.

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Run the dev server**

   ```bash
   npm run dev
   ```

   Open the printed localhost URL (Vite default: <http://localhost:5173>).

## How to Use

- **Discover** — type a need (e.g. "warm sleeping bag for winter camping") and click **Find for me**.
- **Shopping** — type a barcode such as `7610000000011` and click **Scan**.
- **Admin** — no input needed; the dashboard renders automatically from the product data.

## Project Structure

Key files under `frontend/src/`:

```
frontend/
├── .env.example              # VITE_ANTHROPIC_API_KEY template
└── src/
    ├── data/products.json     # 249 SKUs / 69 products, loaded at runtime
    ├── store/useAppStore.ts   # Zustand store (shopping list + app state)
    ├── lib/
    │   ├── claude.ts          # Anthropic SDK client + AI calls (claude-sonnet-4-6)

    └── components/            # Shared UI components
```

## A Note on the AI Features

The Claude API calls are **real, not mocked** — they require a valid Anthropic API key in `VITE_ANTHROPIC_API_KEY`. Without a key, the AI features (recommendations, comparisons, and promotion suggestions) show a friendly error, but the rest of the app still works: you can browse inventory, manage your shopping list, scan barcodes, and view the Admin charts.
